# Reference anatomy attribution

The retained Pterional Craniotomy website contains a regional Z-Anatomy / BodyParts3D derivative and original illustrative tissue surfaces, tools and markings. Native regional anatomy retains its source attribution and applicable share-alike terms: Z-Anatomy CC BY-SA 4.0; upstream BodyParts3D, DBCLS, CC BY-SA 2.1 Japan. Consult the embedded manifest and About/credits for per-asset provenance and known omissions. Keep licenses and source identifiers when reusing these derivatives. These meshes are educational reference anatomy, not patient registration.
